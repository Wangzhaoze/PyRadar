
# Explanation of the MUSIC Algorithm

MUSIC (Multiple Signal Classification) is a high-resolution Direction of Arrival (DOA) estimation method widely used in array signal processing. It separates the signal and noise subspaces and utilizes the array response characteristics of the signal to accurately estimate the arrival directions of multiple signal sources.

We will explain the principles of the MUSIC algorithm step-by-step, along with a schematic diagram to aid understanding.

---

### **1. Problem Background and Model Assumption**

Consider a uniform linear array (ULA) with \( N \) elements receiving plane waves from \( L \) different directions. Each signal source's direction is represented by the Direction of Arrival (DOA), defined as the angle of the incident signal.

As shown below, each antenna (array element) in the array receives signals coming from different directions, and our goal is to estimate the directions (DOAs) of these signals.

```
Signal Source 1
       ↓
        \
Signal  →  [Antenna 1]------[Antenna 2]------[Antenna 3]-----...-----[Antenna N]
        /          |             |               |                 |
       ↓           ↓             ↓               ↓                 ↓
Signal Source L
```

The signal received by each element can be modeled as:
\[
x(t) = A(\theta) s(t) + n(t)
\]
- \( x(t) \) is the signal vector received by the array, of length \( N \).
- \( A(\theta) \) is the array response matrix, describing each signal source's contribution to each element, where \( \theta \) is the signal DOA.
- \( s(t) \) is the signal from the source, of length \( L \).
- \( n(t) \) is the noise, assumed to be Gaussian white noise.

### **2. Array Response Vector**

The array response vector \( a(\theta) \) describes the relative phase and amplitude of the signal at each element when arriving from a certain direction \( \theta \). For a ULA, the array response vector is given by:

\[
a(\theta) = \left[1, e^{-j\frac{2\pi d}{\lambda}\sin(\theta)}, e^{-j\frac{4\pi d}{\lambda}\sin(\theta)}, \cdots, e^{-j\frac{2\pi (N-1) d}{\lambda}\sin(\theta)}\right]^\top
\]

where:
- \( d \) is the spacing between array elements,
- \( \lambda \) is the wavelength of the signal,
- \( \theta \) is the direction of arrival (DOA) of the signal.

### **3. Covariance Matrix**

The received signal data \( x(t) \) can be used to compute the covariance matrix \( R \), which captures the signal characteristics:
\[
R = E[x(t) x(t)^H] = A(\theta) R_s A(\theta)^H + \sigma^2 I
\]
- \( R_s \) is the covariance matrix of the signal sources.
- \( \sigma^2 I \) is the covariance matrix of the noise, assumed to be uniformly distributed.

### **4. Subspace Decomposition**

The core idea of the MUSIC algorithm is **separation of the signal subspace and noise subspace**. By performing an eigenvalue decomposition of the signal covariance matrix \( R \), we can obtain the signal subspace and noise subspace.

1. **Eigenvalue Decomposition**: Decompose the covariance matrix \( R \) into its eigenvalues and eigenvectors:
   \[
   R = V \Lambda V^H
   \]
   where \( \Lambda \) is the diagonal matrix of eigenvalues, and \( V \) is the matrix of corresponding eigenvectors.

2. **Signal and Noise Subspaces**: The first \( L \) larger eigenvalues correspond to the **signal subspace**, and the remaining \( N-L \) smaller eigenvalues correspond to the **noise subspace**.


   - Signal subspace: contains the components generated by the signal sources.
   - Noise subspace: contains only the noise components and no signal information.

### **5. Core Formula of MUSIC Algorithm**

The MUSIC algorithm exploits the fact that the array response vector \( a(\theta) \) is orthogonal to the noise subspace for the true DOAs. Specifically, the array response vector \( a(\theta) \) corresponding to the DOA of a signal source should have zero projection onto the noise subspace.

The MUSIC pseudo-spectrum is given by:
\[
P_{MUSIC}(\theta) = \frac{1}{a(\theta)^H Q_n Q_n^H a(\theta)}
\]
- \( Q_n \) is the matrix of eigenvectors spanning the noise subspace.
- \( a(\theta) \) is the array response vector corresponding to direction \( \theta \).

When \( \theta \) approaches the true DOA, the pseudo-spectrum value tends to infinity. By scanning over the range of angles \( \theta \), we can find the peak positions in the pseudo-spectrum, which correspond to the DOAs of the signal sources.

### **6. DOA Estimation**

Finally, the MUSIC algorithm estimates the DOAs by finding the peaks of the pseudo-spectrum \( P_{MUSIC}(\theta) \).

The diagram below shows the typical shape of the MUSIC pseudo-spectrum, where the horizontal axis represents the DOA \( \theta \), and the vertical axis represents the pseudo-spectrum value. The peaks of the pseudo-spectrum correspond to the estimated DOAs of the signal sources.

```
   P_MUSIC(θ)
    ^
    |
    |                                      *
    |                          *           |
    |                          |           |
    |              *           |           |
    |              |           |           |
    |    *         |           |           |
    |    |         |           |           |
    --------------------------------------------------> θ (DOA)
          θ_1      θ_2         θ_3         θ_4
```
- The peaks at angles \( \theta_1, \theta_2, \theta_3 \) are the estimated DOAs by the MUSIC algorithm.

---

### **7. Summary**

The core steps of the MUSIC algorithm:
1. Compute the covariance matrix \( R \) of the received signal.
2. Perform eigenvalue decomposition on \( R \) to obtain the signal subspace and noise subspace.
3. Use the orthogonality between the noise subspace and the array response vector for DOA estimation by calculating the MUSIC pseudo-spectrum.
4. Estimate the DOAs by searching for peaks in the pseudo-spectrum.

Compared to traditional beamforming methods, the MUSIC algorithm has much higher resolution and is particularly suitable for high-precision DOA estimation in the presence of multiple signal sources. However, its computational complexity is relatively high, requiring significant computational resources.
